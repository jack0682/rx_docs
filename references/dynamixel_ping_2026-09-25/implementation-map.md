Existing trusted OS/installed binaries and whole-state rollback limits persist.

- Unknown native outcome test uses an external OS observer to kill the actual helper during fixed simulated response latency. No production fault injection flag. The helper's audit entry is independent from Host native SQLite commit.
- Failure residual: trusted installation stability between verified byte acquisition and fixed-path spawn remains the established G2 boundary. Arbitrary same-UID ptrace/FD theft/root/malicious replacement are not sandboxed.
