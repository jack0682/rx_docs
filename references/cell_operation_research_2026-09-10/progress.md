# 셀 운영 계약 확정 작업

목표: 셀의 운전 조건·실행 허가·작업자 개입·복구 계약을 충분한 조사와 근거에 따라 확정한다.

현재 목표 회차는 진행이다. 기존 v1.0 원문/manifest와 자사 5개 저장소 HEAD를 재확인했고, 산업 제어·정지/재기동·위험 에너지·공급사 복구 자료를 대조했다. 구현·실물 시험은 수행하지 않는다.

- [x] N01 첫 셀 사용 범위·대상·조건과 확인되지 않은 현장 입력
- [x] N02 SR01 전체 개입·복구, SR02 상실·지지, SR03 변경 재검토의 사건 계약
- [x] N03 위험·필요 기능·책임·증거·검증의 연결
- [x] N04 사용 범위/현재 조건/시작 의도/실제 보호 기능 구분, 허가·무효화·경합
- [x] N05 역할·운영 UI·장비 binding·자사 모델 차이·변경 영향
- [x] N06 기존 계약 재사용/필수 확장/혼합 버전 거부·반례·검증·완료 감사
- [x] 원문 근거와 설계 선택/배제 이유
- [x] 독립 독자 검토와 지적 보완
- [x] 문서 무결성·기존 기준판 보존·최신 안내 연결

완료 기준은 설계 계약의 규범적 결론과 요구별 검토 증거다. 현장 신호·교정·반응 시간·실제 안전 성능이 확인되지 않은 조합을 운전 허용/인증 완료로 표시하지 않는다. 실제 binding의 필수 입력과 미확인 시 거부 규칙을 계약에 포함한다.

완료 감사: completion_audit.json, 독립 의미/protocol 독자의 지적 보완 및 재검토, 문서/manifest/source 확인을 완료했다. OV01–OV11과 첫 셀 NOT_COMMISSIONED는 실행/현장 단계의 상태로 유지한다.
