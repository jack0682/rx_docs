# Workflow 세로 경로의 제외 범위

2026-10-01 사용자 지정: 0F 레이저 열처리 단일 그리퍼 모의 경로의 M1–M3에서만 제외한다. 기존 WF/RF 장기 목표는 유지한다.

- 듀얼 그리퍼(WF17): 이번 경로는 단일 그리퍼만 사용한다.
- 버퍼(WF17): 별도 버퍼 자원을 추가하지 않는다.
- 회전 정렬 장비(WF17): 이번 경로에 포함하지 않는다.
- Target Group(WF08): 한 품목을 N회 처리하는 범위로 한정한다.
- 다중 로봇 인계(WF12): 로봇 한 대만 사용한다.
- ParallelAny와 이 흐름에 필요하지 않은 조건 반복: 추가하지 않는다.
- 다중 운영 영역: 이번 모의 경로에 포함하지 않는다.
- 물리 장비: FILE_SIMULATION 또는 기존 모의 provider만 사용한다.
- BT 자동 생성: 이번 경로에 포함하지 않는다.
- 새 거버넌스 또는 릴리스 정책: 기존 절차를 사용한다.
- R7 복구 WIP 흡수: 이 경로의 차단 근거가 확인되기 전에는 포함하지 않는다.
- 재자격 WIP 흡수: 이 경로의 차단 근거가 확인되기 전에는 포함하지 않는다.
